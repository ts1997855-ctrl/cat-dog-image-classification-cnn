# 🐱🐶 Cat vs Dog Image Classification using Convolutional Neural Networks

## 📌 Project Overview

This project implements a deep learning image classification system using TensorFlow and Keras to distinguish between images of cats and dogs.

Four different neural network architectures were developed, trained, and evaluated to compare their classification performance.

---

## 🚀 Features

- Image preprocessing and normalization
- Basic Neural Network
- CNN with One Convolution Layer
- CNN with Two Convolution Layers
- Bigger CNN with Three Convolution Layers
- Performance comparison using accuracy and loss
- Model evaluation and visualization
